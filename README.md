# 内蒙古企业出海一站通（原型）

面向内蒙古企业的出海综合服务平台，**零构建纯静态站点**（HTML + CSS + 原生 JS，无框架、无依赖），整个文件夹复制到任意静态托管（GitHub Pages / 阿里云 OSS / Nginx）即可运行。

## 板块

| 路由 | 板块 | 说明 |
|---|---|---|

## 文件

- `index.html` — 外壳（页眉、页脚、弹窗）
- `assets/js/data.js` — **全部内容数据**，改文案只改这里
- `assets/js/app.js` — 路由与渲染
- `assets/css/style.css` — 样式（苍穹蓝 / 草原绿 / 鎏金 / 哈达白）
